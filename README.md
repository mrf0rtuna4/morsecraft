# Morsecraft

---

![craft](https://cdn.modrinth.com/data/cached_images/117371bda491d2af181537bc79ce65cf27d8ac9d.png)

Morsecraft adds a fully functional **Telegraph Key** to Minecraft, allowing you to send Morse code messages, print them on paper tape, and interact with redstone. This mod brings a touch of historical communication technology into your survival or creative gameplay!

## Features

* **Telegraph Key Block**

  * Placeable block for entering Morse code (dots `.` and dashes `-`).
  * Produces authentic telegraph sounds for dots and dashes.
  * Interacts with redstone signals.
  * Displays player messages including remaining paper and printed symbols.

* **Paper & Charging**

  * Telegraphs require paper to operate.
  * Craft telegraph + paper to charge it.
  * 1 sheet of paper allows 10 Morse code symbols to be recorded.

* **Paper Tape**

  * Records the sequence of Morse code symbols from the telegraph.
  * Can be extracted from the telegraph block.
  * Supports both empty and filled tapes with localized messages.

* **Gameplay Mechanics**

  * Right-click: record a dot `.`
  * Shift + Right-click: record a dash `-`
  * Sequence clears automatically if idle for too long.
  * Destroying the telegraph drops the block with its remaining paper intact.

* **Creative Mode**

  * New creative tab `Morsecraft` for easy access to all items and blocks.

## Planned Features (Future Updates)

* Improved paper tape printer with customizable display.
* More telegraph models and textures.
* Optional sound customization and key bindings.
